# متروجو — ورکر صدای فارسی ☁️ (Cloudflare Workers — پلن رایگان)

این فایل `metrojo-voice-worker.js` یک‌بار برای همیشه استقرار داده می‌شود؛ کاربران اپ فقط مصرف‌کننده هستند و هیچ کاری انجام نمی‌دهند.

## استقرار از طریق داشبورد (بدون نصب چیزی — ۳ دقیقه)

1. وارد <https://dash.cloudflare.com> شوید (اگر حساب ندارید، ثبت‌نام رایگان — فقط ایمیل لازم است).
2. از منوی چپ: **Compute & AI → Workers & Pages** را باز کنید.
3. دکمه **Create application / Create Worker** را بزنید.
4. نام: `metrojo-voice` (یا هر نام دلخواه) → **Deploy** را بزنید (کد پیش‌فرض مهم نیست).
5. روی **Edit code** کلیک کنید.
6. همه‌ی کد پیش‌فرض را پاک کنید و **کل محتوای فایل `metrojo-voice-worker.js`** را جای‌گذاری (Paste) کنید.
7. **Deploy** را بزنید.
8. آدرس ورکر را کپی کنید — به شکل زیر است:
   `https://metrojo-voice.<نام-حساب-شما>.workers.dev`

## چک سلامت

این آدرس را در مرورگر باز کنید؛ اگر `{"ok":true,...}` دیدید همه‌چیز آماده است:

```
https://metrojo-voice.xxx.workers.dev/health
```

تست صدا در مرورگر:

```
https://metrojo-voice.xxx.workers.dev/tts?text=سلام%20دنیا&gender=female
```

## قدم آخر

آدرس ورکر را برای ثبت در اپ (ثابت بیلد `CLOUD_TTS_BASE`) بفرستید.
از آن پس نسخه وب و نسخه اندروید هر دو صدای ابری دلاارا/فرید را همان‌جا می‌گیرند — بدون هیچ تنظیمی از سمت کاربر.

## محدودیت پلن رایگان (بسیار کافی)

- **۱۰۰,۰۰۰ درخواست در روز** — برای یک اپ شخصی/خانوادگی چند صدم برابر نیاز است.
- پاسخ‌های تکراری در خود ورکر کش می‌شوند و دوباره از مایکروسافت گرفته نمی‌شوند.
- نیازی به کارت بانکی، دامنه یا تنظیم DNS نیست.
