# 🎙️ استقرار ورکر صدای فارسی متروجو روی کلودفلر

این پوشه کد کامل ورکر صدای ابری متروجو است (صدای عصبی فارسی مایکروسافت — دلاورا/فرید).
**نیازی به هیچ کلید، API یا حساب مایکروسافت نیست** — رایگان روی پلن Free کلودفلر اجرا می‌شود.

دو راه استقرار وجود دارد — **فقط یکی را انتخاب کنید:**

---

## راه ۱ (پیشنهادی — خودکار): توکن به من بدهید تا خودم مستقر کنم

فقط این دو مورد را برای من بفرستید:

| مورد | از کجا بگیرید |
|---|---|
| **Account ID** | داشبورد کلودفلر → صفحه اصلی (سمت راست) → کپی `Account ID` |
| **API Token** | داشبورد → آیکون پروفایل → **My Profile** → **API Tokens** → **Create Token** → قالب **«Edit Cloudflare Workers»** → Create → کپی توکن |

بعد از ارسال، من با دستور زیر مستقر می‌کنم و آدرس را داخل اپ ثبت می‌کنم:

```bash
cd cloudflare-worker
CLOUDFLARE_ACCOUNT_ID=<your-account-id> \
CLOUDFLARE_API_TOKEN=<your-token> \
bunx wrangler deploy
```

⚠️ بعد از اتمام کار می‌توانید آن توکن را از داشبورد حذف کنید.

---

## راه ۲ (دستی): خودتان در داشبورد بسازید — حدود ۲ دقیقه

1. وارد [dash.cloudflare.com](https://dash.cloudflare.com) شوید.
2. از منوی کنار: **Workers & Pages** → دکمه **Create** → **Create Worker**.
3. نام: `metrojo-voice` → دکمه **Deploy** (کد پیش‌فرض مهم نیست).
4. روی **Edit Code** بزنید.
5. تمام کد فایل `worker.js` همین پوشه را انتخاب و کپی کنید (Ctrl+A → Ctrl+C در فایل) و جایگزین کد ادیتور کنید (Ctrl+A → Ctrl+V).
6. دکمه **Deploy** را بزنید.
7. آدرس بالای صفحه را کپی کنید — چیزی شبیه:
   `https://metrojo-voice.<نام-حساب>.workers.dev`
8. همین آدرس را برای من بفرستید تا در اپ ثبت و APK بازسازی شود.

### تست بعد از استقرار
در مرورگر این آدرس را باز کنید:
```
https://<آدرس-ورکر>/tts?text=سلام%20دنیا&gender=female
```
اگر صدای فارسی پخش شد، همه‌چیز درست است ✅

---

## بعد از دریافت آدرس چه می‌شود؟

من آدرس را در `src/lib/cloud-config.ts` ثبت می‌کنم:
```ts
export const CLOUD_TTS_BASE = "https://metrojo-voice.xxx.workers.dev";
```
و APK را بازسازی می‌کنم. آنگاه **همه کاربران** نسخه وب و اندروید به‌صورت خودکار صدای ابری دلاورا/فرید را می‌گیرند — بدون هیچ تنظیمی از طرف آنها. کاربر فقط مصرف‌کننده است.

---

## پلن رایگان کلودفلر چقدر جواب می‌دهد؟

| محدودیت | سهمیه رایگان | مصرف متروجو |
|---|---|---|
| درخواست | ۱۰۰٬۰۰۰ در روز | هر جمله = ۱ درخواست (با کش داخل ورکر کمتر می‌شود) |
| زمان CPU | ۱۰ ثانیه در هر درخواست | تولید صدا عمدتاً انتظار شبکه است — کمتر از ۵۰ms CPU |
| WebSocket خروجی | ✅ پشتیبانی کامل | همین مبنای پروتکل Edge است |
