# سرور ابری درمسیر — Cloudflare Workers + D1 (رایگان)

سرور API اپ و پنل روی زیرساخت رایگان کلادفلر:
- **Cloudflare Workers**: ۱۰۰ هزار درخواست در روز (رایگان)
- **Cloudflare D1**: دیتابیس SQLite در لبه — ۵ گیگ (رایگان)

## مراحل deploy (یک‌بار، حدود ۵ دقیقه)

```bash
cd cloudflare-worker

# 1) ورود به کلادفلر (مرورگر باز می‌شود)
npx wrangler login

# 2) ساخت دیتابیس ابری رایگان
npx wrangler d1 create darmasir-db
#    → خروجی database_id را در wrangler.toml جایگزین کنید

# 3) ساخت جداول در دیتابیس ابری
npx wrangler d1 execute darmasir-db --remote --file=schema.sql

# 4) انتشار سرور
npx wrangler deploy
```

آدرس نهایی: `https://darmasir-api.<زیردامنه شما>.workers.dev`

## اتصال پنل به سرور ابری

پنل مدیریت → **تنظیمات سامانه** → کارت «سرور ابری (Cloudflare)»:
1. آدرس Worker را در «آدرس سرور ابری» ذخیره کنید
2. «تست اتصال ابر» → باید `reachable: true` بدهد
3. «همگام‌سازی محتوا با ابر» → همه شهرها/خطوط/ایستگاه‌ها/بنرها/تنظیمات/واژگان به D1 کپی می‌شود

پس از هر تغییر محتوا در پنل، دکمه همگام‌سازی را بزنید (یا بعداً autosync فعال شود).

## اتصال اپ به سرور ابری

متغیر محیطی `CLOUD_API_BASE` را روی آدرس Worker بگذارید؛ اپ به‌ترتیب:
**سرور ابری → پنل محلی → کش آخرین نسخه** را امتحان می‌کند.

## پیامک واقعی (کاوه‌نگار)

```bash
npx wrangler secret put KAVENEGAR_API_KEY
```
قالب تایید «darmasir» را در پنل کاوه‌نگار بسازید. بدون کلید، حالت توسعه فعال است
(کد در پاسخ برگردانده می‌شود — فقط برای تست).

## امنیت

- همگام‌سازی محتوا/کاربر فقط با هدر `X-Sync-Key` (متغیر `DARMASIR_SYNC_KEY` در wrangler.toml)
- رمزها با PBKDF2-SHA256 (۱۰۰ هزار دور) هش می‌شوند
- نشست‌ها: توکن Bearer با اعتبار ۳۰ روز
- CORS باز برای اپ (PWA/APK) — فقط مسیرهای عمومی
