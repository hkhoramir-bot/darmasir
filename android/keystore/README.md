# Keystore امضای متروجو

این keystore تنها منبع امضای پایدار پروژه است و **باید هرگز حذف نشود**.

## چرا وجود دارد؟
کلید debug خودکار اندروید (`~/.android/debug.keystore`) مختص ماشین است و در محیط‌های
سندباکس بین جلسات پاک می‌شود. اگر امضا عوض شود، نصب به‌روزرسانی روی نسخه قبلی ناموفق
خواهد بود (خطای امضا) و کاربر مجبور به حذف کامل برنامه می‌شود. با امضای همه buildTypes
(debug و release) با این keystore ثابت، امضا در تمام buildها یکسان می‌ماند.

## فایل‌ها
| فایل | توضیح |
|---|---|
| `metrojo.keystore.pkcs12` | استور PKCS12 با alias `metrojo`، اعتبار ۳۰ سال |
| `../keystore.properties` | مسیر استور، نوع، رمزها و alias (خوانده‌شده در `app/build.gradle`) |

## نحوه استفاده
هیچ تنظیم اضافه‌ای لازم نیست — `app/build.gradle` به‌طور خودکار `android/keystore.properties`
را می‌خواند و هر دو buildType را با آن امضا می‌کند. دستورهای ساخت:

```bash
bunx cap sync android
cd android && JAVA_HOME=<jdk> ./gradlew assembleDebug   # یا assembleRelease
```

## ملاحظات امنیتی
این مخزن خصوصی است و رمز داخل `keystore.properties` کامیت شده تا ساخت در جلسات آینده
بدون گم‌شدن امضا انجام شود. اگر روزی پروژه به مخزن عمومی منتقل شد، این فایل‌ها را حذف و
رمز را از طریق متغیر محیطی/CI secret تامین کنید.

## تاریخچه امضا
- نسخه‌های ۴.۸.۷ تا ۴.۸.۱۶: با کلید debug خودکار ماشین (که از بین رفته) امضا شده‌اند.
- از اولین build بعدی: امضای این keystore (`CN=Metrojo, O=Metrojo`).
  کاربران فعلی برای رفتن به نسخه با امضای جدید، **یک بار** باید برنامه قبلی را حذف کنند
  (داده‌های محلی پاک می‌شود)؛ از آن به بعد همه به‌روزرسانی‌ها بدون حذف نصب می‌شوند.
