## API

### `GET /api/v1/ads`
`requireAdmin` → لیست همه کمپین‌ها (مرتب بر اساس createdAt نزولی) + `stats` جمعی: total, activeNow, scheduled, expired, inactive, impressions, clicks, avgCtr.

### `POST /api/v1/ads`
اعتبارسنجی دستی: title لازم (≤۱۲۰)، placement در لیست مجاز، startAt/endAt معتبر و start<end، linkUrl اختیاری ولی باید `http(s)://` باشد، body/imageUrl اختیاری. سپس ایجاد + `logAudit("CREATE","AD",id,{title,placement,active})` → 201.

### `PATCH /api/v1/ads/[id]`
فیلدهای مجاز: title/body/linkUrl/imageUrl/placement/startAt/endAt/active. اعتبارسنجی ترکیبی بازه زمانی (جدید + موجود). 404 برای شناسه ناموجود. + `logAudit("UPDATE","AD",id,{fields,active})`.

### `DELETE /api/v1/ads/[id]`
فقط SUPERADMIN (403 برای بقیه) + `logAudit("DELETE","AD",id,{title})`.
